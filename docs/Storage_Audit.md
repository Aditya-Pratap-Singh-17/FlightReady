## Cleanup classification

### A. Safe to delete automatically

- Python `__pycache__` directories and `*.pyc` files.
- `.pytest_cache` and generated test caches.
- `.npm-cache` download cache.
- Temporary PDF render files under `tmp/pdfs/` after visual verification.

### B. Delete after verification and explicit approval

- VisDrone generated variants (18.47 GiB).
- Prepared VisDrone extraction/conversion (1.834 GiB).
- Public VisDrone archives (1.815 GiB, including checkpoint download).
- Training-run prediction JSON, redundant `last.pt`, and optional full run directories (0.700 GiB).
- Historical `.runtime` workbench/test/smoke artifacts (1.889 GiB).
- `.venv`, `.packages`, `frontend/node_modules`, and `frontend/dist` if immediate local execution is not required.
- Git loose-object maintenance/pruning.

### C. Preserve

- All application source, tests, requirements, metric/scoring configuration, and documentation.
- Experiment scripts, compact result tables/JSON, manifests, provenance, certificates, reports, and publication figures.
- Final submission Markdown and PDFs.
- Any local dataset or model whose provenance/recoverability is uncertain.

## Secrets and machine-specific configuration

- `.env` is ignored and contains a populated Gemini API key. The value was not printed, copied, or committed.
- `.env.example` contains empty placeholders and portable relative defaults.
- New submission documentation uses repository-relative commands rather than requiring a personal drive path.
- Raw datasets, generated variants, downloaded archives, model weights, runtime state, dependency environments, and training runs are ignored.
